# Caesar Cipher

Консольное приложение для шифрования и дешифрования файлов с использованием шифра Цезаря.  
Поддерживает русский и английский алфавиты, цифры и основные символы.

## Возможности

- Шифрование файла с заданным ключом
- Дешифрование файла с заданным ключом
- Работа с большими файлами (буферизация)
- Автоматическое создание директорий для выходных файлов
- Консольное меню


## Структура проекта

- CaesarAlphabet — алфавит (русский, английский, цифры, символы)
- CaesarCipher — шифрование/дешифрование символов
- CaesarFileProcessor — работа с файлами
- ConsoleMenu — меню приложения
- MenuOption — пункты меню
- PathValidator — валидация и подготовка путей файлов
- Application — главный класс(точка входа)
